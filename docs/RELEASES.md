# Lanefall — Release notes

## v0.3 (web prototype, frozen 2026-11-02)
Single HTML file in `prototype-web/lanefall-v0.3.html`. Kept as the rules reference; no further changes.
- 8 heroes (Bulwark, Butcher, Blademaster, Shade, Pyra, Frostbow, Lumen, Quake), 17 items, levels 1–6.
- Three maps: The Rift (3 lanes), Twin Hollow (2 lanes, altars, Spider Queen), Frost Bridge (1 lane, all random).
- 1v1 to 4v4, bots (easy/normal/hard), hotseat and online rooms.
- Marksman free attack, recall at any time, full heal in your base.
